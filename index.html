Main Features

Everything you need in an AI-powered coding assistant, right in your terminal

🛠

19 Built-in Tools

File operations, PowerShell command execution, web search, OCR, self-healing, and more. Each tool is designed to interact with your system safely and efficiently.

⚡

8 Specialized Skills

Predefined workflows for debugging, code generation, web research, refactoring, system administration, data extraction, and documentation.

🧠

Persistent Memory

Long-term memory that persists across sessions. PSCoder remembers your preferences, projects, and previous solutions to provide more contextual answers.

🎓

Self-Learning

Automatically saves errors, solutions, and patterns for future reference. The system learns from every interaction and continuously improves its answers.

💉

Self-Recovery

Diagnoses errors and suggests solutions with alternative approaches. Classifies errors by type and provides quick-fix commands and recovery strategies.

📁

Session History

Saves, lists, and loads previous conversations. Each session captures messages, model, provider, tokens, cost, and working directory for full continuity.

8 Specialized Skills

Predefined workflows that the agent loads automatically based on the task

Research

Web Research

Searches, fetches, and synthesizes up-to-date information from the web. Includes version compatibility checks and searching with alternative terms.

Analysis

File Analysis

Analyzes project structure, codebases, and configurations. Builds a mental map of the project by reading entry points first.

Debug

Debug Error

Diagnoses and resolves errors with a systematic 9-step solution: check version, auto-heal, search for solutions, read code, apply fix, and verify.

Generation

Code Generation

Creates new scripts, functions, and modules from scratch. Respecting the project's style, adding error handling, and without inventing nonexistent APIs.

Refactor

Refactor

Improves code quality, readability, and performance without changing functionality. Small, testable changes, without over-engineering.

Admin

PowerShell Admin

Windows system administration tasks: services, processes, registry, users, networks, and permissions. Recommends -WhatIf for destructive operations.

Data

Data Extraction

Parses and transforms data from files, APIs, and web pages. Uses regex, ConvertFrom-Json/Xml, and encoding handling for clean extraction.

Docs

Documentation

Creates and improves project documentation. Includes code examples, parameter documentation, and return values.

Quick Start

Start using PSCoder in 3 simple steps

1

Clone the repository

Copy the GitHub repository to your local machine and navigate to the project directory.

PowerShell
git clone https://github.com/josevdr95new/PSCoder.git
cd PSCoder
2

Configure your API key

You need an API key for the custom OpenAI-compatible endpoint (slop.storo.cloud) or Groq. Configure it as an environment variable or interactively.

PowerShell - Option 1: Environment variable
$env:SLOP_API_KEY = "your-key-here"
PowerShell - Option 2: Interactive configuration
Start-PSCoder
# Then use: /config apiKey your-key-here
3

Start PSCoder

Run the assistant and start interacting with the AI. You can also use the .bat file for Windows.

PowerShell
# Import and run
Import-Module .\PSCoder.psd1
Start-PSCoder

# Or directly:
.\Start-PSCoder.ps1

# Or with a specific model:
.\Start-PSCoder.ps1 -Model "deepseek-v4.1-flash" -Provider "custom"

Intelligent Systems

Advanced mechanisms that make PSCoder autonomous and self-improving

🧠

Memory Decision

Analyzes each conversation turn and automatically decides what information is worth persisting: resolved errors, user preferences, project context, success patterns, and command flows.

⚙

Reasoning Engine

Planning engine that creates step-by-step plans with suggested tools and success criteria. Verifies each step individually and the complete task, with self-healing if a step fails.

🔒

Permissions System

4 permission modes: Default (auto-approved reads), AcceptEdits (auto-approve everything), BypassPermissions (no approval), and Plan (reads only). Detects dangerous commands like Remove-Item or Format-Volume.

🔔

Hooks

Hook system with PreToolUse (can block execution), PostToolUse (runs after execution), and Stop (at the end of each turn). Customizable scripts in ~/.pscoder/hooks/.

📊

Context Builder

Automatically includes Git status (recent commits, uncommitted changes) and looks for PSCODER.md files with project-specific instructions. 2-minute in-memory cache.

🎤

Agent Narration

Visual and voice feedback for the agent's actions. Uses Windows SAPI for text-to-speech, with distinct colors for thoughts, actions, results, and errors.

Data Storage

All user data is stored in ~/.pscoder/ — nothing sensitive in the repository

~/.pscoder/
    config.json — Configuration (API keys, model, etc.)
    MEMORY.md — Long-term memory
    Sessions/ — Saved conversation sessions
    improve/
        learnings.json — Recorded learnings
        patterns.json — Learned patterns
    cache/ — Web search/fetch cache
    reasoning/ — Plan history
    memory_decisions/ — Automatic decision log
    hooks/ — Custom hook scripts

AI Providers

Compatible with multiple providers and language models

🌐

Custom (slop.storo.cloud)

Custom OpenAI-compatible endpoint. Default model: deepseek-v4.1-flash. Hot-swap models with /model.

⚡

Groq (Fast Inference)

Ultra-fast inference for Llama, Mixtral, Gemma, and Qwen. Ideal for quick responses. Supports reasoning_effort and max_completion_tokens.

Change model and provider
# Change model
/model deepseek-v4.1-flash

# Change provider
